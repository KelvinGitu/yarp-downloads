# Yarp Developers downloads

Installers for the Yarp Developers desktop apps for Windows 10 and 11. This
repository holds downloads only; there's no source code here.

| App | What it does | Download |
|---|---|---|
| **pdfsign** | Fill, sign and mark up PDFs without uploading them anywhere | [pdfsign-setup.exe](https://github.com/KelvinGitu/yarp-downloads/releases/latest/download/pdfsign-setup.exe) |
| **Resume Maker** | Write your resume once, set it in seven styles, export a clean PDF | [ResumeMaker-setup.exe](https://github.com/KelvinGitu/yarp-downloads/releases/latest/download/ResumeMaker-setup.exe) |

Both run entirely on your computer and make no internet connections. Every
download is a free trial (3 exports); a licence key from
[yarpdevelopers.com/store](https://yarpdevelopers.com/store) unlocks it for good.

Windows may show "Windows protected your PC" the first time: click
**More info**, then **Run anyway**.
